# Vendor Risk Standard

## Assurance reports

Every vendor that processes customer data must provide a current SOC 2 Type II report or ISO 27001 certificate. A report older than 12 months is not current.

## Data processing agreements

A signed data processing agreement must be on file before a vendor receives customer data.

## Annual review

The security team reassesses each critical vendor once per calendar year and records the outcome in the vendor register.
